## ผลวินิจฉัยล่าสุดต่อโลก (4aa)
คอขวดอยู่ที่ **matching ไม่ใช่ retrieval** ในทุกโลกใหม่: ผลจริง = ผล oracle (retrieval สมบูรณ์) เกือบพอดี และจำนวน match เฉลี่ยลดตามความยาก (โลกเดิม 349 → grid11 53 → bridge14 35 → oldtown12 11 → canyon15 7) retrieval แย่ลงด้วย (R@50 64% → 10–45%) แต่เป็นตัวจำกัดลำดับถัดไป
gate ที่เรียนรู้ข้ามโลกถ่ายโอนได้ดี (AUROC 0.96–0.99) และดีกว่าเกณฑ์ inlier เดี่ยวมากในโลกที่ยากสุด (oldtown12: 51.5% เทียบ 6.1% ของเฟรมที่ได้ pose ที่ precision ≥95%)

## ลำดับที่ควรลองแก้ (คุ้มที่สุดก่อน)
1. **ช่องว่าง render ↔ ภาพจริง** (ตัวขับผลที่ต่ำใน grid11): refine ด้วย render ที่ตำแหน่งประมาณ + matcher ใหม่ (RoMa v2 ต้องดาวน์โหลด อนุญาตแล้ว) + render ละเอียดขึ้น
2. **ผนังระดับถนนขาด** (canyon15): บินต่ำตามถนน/หุ่นลงสีเอง แล้วเทียบ
3. **เลนส์และ calibration**: ใส่ขั้นตอน undistort และตรวจมุมอัตโนมัติ
4. **ตัวกรอง**: หลายสมมติฐานในลูปวงปิด; ตรวจสี่แยกที่หลุด
5. **SLAM โดรนล้มในที่โล่ง**: ทางแก้ระดับระบบ (ไม่ใช่ซอฟต์แวร์ของเรา)
